Quick guide

How to play

  1. 1
    Choose team race or solo

    Team mode uses a fair badge toss for first turn. Solo mode starts immediately.

  2. 2
    Discuss before answering

    In Recall mode, answer aloud. Showing four choices reduces the reward to half a panel.

  3. 3
    Reveal and explain

    The facilitator marks the response, then reads the explanation and document reference with the group.

  4. 4
    Install to finish

    Complete the selected panel target. In team mode the first crew there wins; solo mode tracks your own run.
